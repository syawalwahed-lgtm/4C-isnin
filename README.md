## Fail
- `index.html` — permainan lengkap, boleh dimainkan terus dalam pelayar.

## Cara main
1. Buka `index.html` dalam pelayar web.
2. Tekan **Mula Misi!**
3. Gerakkan Pac-Man menggunakan butang arah atau kekunci anak panah dan kutip 3 titik.
4. Jawab 25 soalan. Jawapan betul memberikan 10 mata dan satu bintang.
5. Butang Bunyi mengawal kesan bunyi dan suara Bahasa Melayu peranti (jika tersedia).

## Terbitkan melalui GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `bm-tahun4-arcade`.
2. Muat naik `index.html` dan `README.md` ke akar repositori.
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**, pilih `main` dan folder `/(root)`, kemudian **Save**.
5. Selepas penerbitan selesai, pautan lazimnya `https://NAMA-PENGGUNA.github.io/bm-tahun4-arcade/`.

Nota: permainan ini menggunakan Web Speech API untuk suara jika pelayar/peranti menyokong Bahasa Melayu. Semak nombor Standard Kandungan/Standard Pembelajaran pada DSKP rasmi yang digunakan oleh sekolah sebelum edaran.
